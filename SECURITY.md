# Security Policy

## Supported versions

Only the latest published version of `zenty` receives security fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report it privately through GitHub instead:
[Report a vulnerability](https://github.com/zentylib/zenty/security/advisories/new)
(repository **Security** tab → **Report a vulnerability**).

Include what is affected, steps to reproduce, and the impact you expect. You should get a
response within a few days. Once a fix is released, the advisory will be published with
credit to you unless you prefer to stay anonymous.
